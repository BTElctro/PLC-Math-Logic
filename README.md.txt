# PLC Math & Logic Studio Pro 🛠️🤖

**PLC Math & Logic Studio Pro** is an advanced engineering desktop application designed for automation and PLC engineers. It converts mathematical equations and logical expressions into visual **Function Block Diagrams (FBD)** and generates standardized **Structured Text (ST)** code automatically.

استوديو هندسة الـ PLC هو تطبيق احترافي مصمم لمهندسي الأتمتة والتحكم الرقمي، يقوم بتحويل المعادلات الرياضية والمنطقية إلى مخططات بلوكات وظيفية مرئية (FBD) وتوليد كود النص المهيكل القياسي (ST) تلقائياً.

---

## ✨ Features / المميزات

* **Multi-Language Support:** Full dynamic support for English 🇬🇧, Arabic 🇸🇦, and Français 🇫🇷.
* **Visual FBD Generation:** Intelligent block placement and automated uppercase conversion.
* **Math & Logic Keypad:** Built-in interactive keypad for quick symbol entry without relying on keyboards.
* **Advanced Export Options:** Users can flexibly capture high-quality screenshots (PNG) or generate formal PDF reports for engineering documentation.
* **ST Code Preview:** Real-time generation of PLC-compliant Structured Text with variable data type selection.
* **نظام متعدد اللغات:** دعم كامل وديناميكي للغات العربية، الإنجليزية، والفرنسية.
* **توليد مخططات مرئية:** توزيع ذكي ومتباعد للبلوكات مع تحويل تلقائي لحروف Majuscule.
* **لوحة مفاتيح هندسية:** أزرار تفاعلية مدمجة لسرعة كتابة الرموز والبوابات المنطقية.
* **خيارات تصدير مرنة:** إمكانية التقاط لقطات شاشة نقية أو توليد تقارير PDF رسمية للمشاريع.
